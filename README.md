# BOAS-SE Corporate Solution: 기업 공식 웹사이트 및 통합 관리 솔루션

기업의 디지털 브랜드 아이덴티티와 효율적인 자산 관리를 동시에.
실무 인턴십 기간 동안 구축한 기업 공식 홍보 사이트 및 내부 자산/채용 관리 시스템입니다.

### 프로젝트 소개
- 프로젝트 명: BOAS-SE 공식 웹사이트 및 어드민 시스템
- 개발 기간: 2026.01 (2주 인턴십)
- 주요 타겟: 기업 방문 고객 및 사내 인사/자산 관리자

### 개발 배경 (Why?)
1. 기업 브랜드 이미지 구축: 신뢰감 있는 UI와 애니메이션을 통해 기업의 전문성을 시각적으로 전달해야 했습니다.
2. 관리 비효율성 개선: 공지사항, 제품 소개, 채용 정보를 수동으로 업데이트하는 대신, 일관된 관리자 도구를 통해 데이터를 중앙 제어하고자 했습니다.
3. 데이터 보안 및 일관성: 유실될 위험이 있는 로컬 파일 저장 대신, 데이터베이스 내 직접 저장을 통해 관리 편의성과 보안성을 강화했습니다.
